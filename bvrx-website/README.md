# BVRX Website

Static, mobile-friendly landing page for the BVRX BEP-20 token project.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
Deploy the `bvrx-website/` directory as a static site on a host such as Vercel. Configure the project root to `bvrx-website` and use no build command; output is the current directory.

## Status accuracy
The page intentionally says testnet deployment is pending. Add a contract address, explorer link, swap links, staking or governance claims only after the relevant functionality is implemented and independently verified. BVRX is separate from the Fleur Network protocol.
